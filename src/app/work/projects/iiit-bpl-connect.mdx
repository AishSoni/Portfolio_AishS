## Overview

IIIT Bhopal Connect is a campus platform that brings student communication, institute resources, events, and career support into one place. It was designed as a student-centric integrated information system rather than a collection of disconnected utilities.

## Features

- Campus posts, feeds, profiles, event management, lost and found, timetables, study materials, and notifications.
- Firebase Authentication, Firestore, cloud storage, security rules, and real-time synchronization for dynamic content.
- Career-focused features including peer resume review, AI-assisted cover-letter generation, and a chat assistant for opportunity-related questions.
- Responsive interfaces for students and organizers, with a component-based Next.js/React frontend and server-side actions for data operations.

## Development

The project followed an iterative workflow with feature-focused sprints, functional and integration testing, usability checks, and CI/CD practices. The main engineering challenge was keeping a broad campus feature set coherent while protecting user data and making AI features assistive rather than opaque.

## Stack

Next.js, React, Firebase Authentication, Firestore, Cloud Storage, real-time listeners, and AI integrations.
